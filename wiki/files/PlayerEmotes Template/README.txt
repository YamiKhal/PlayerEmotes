PlayerEmotes Template

player_emote_template.geo.json            open in Blockbench (File > Open Model), straight arms and legs
player_emote_template_bendable.geo.json   same, with elbows and knees you can bend
My Emote Pack                             resource pack, put it in .minecraft/resourcepacks
My Server Emotes                          data pack, put it in <world>/datapacks for server emotes

Export your animations into My Emote Pack/assets/myemotes/playeremotes/my_emotes/
and press the Reload Emote Files key in game (set it in Controls first, it's unassigned).

Everything else is on the wiki: https://github.com/YamiKhal/PlayerEmotes/wiki
